# AI Coding Agent Directives & Project Rules

## Design System Enforcement
* **Primary Reference**: All UI and UX implementations MUST strictly follow the design tokens, typography, layout hierarchy, and component rules defined in `/DESIGN.md`.
* **Visual Direction**: Brutalist Haute Couture & Editorial Luxury (high contrast, crisp 1.5px/2px keylines, deep crimson `#7A0000` accents, uppercase Syne / Space Mono typography, no generic bubbly AI templates).
* **Responsive Discipline**: Always ensure layout responsiveness on mobile (min 44px touch targets) and desktop (`max-w-7xl`, subtle hover lifts, hard drop shadows).
